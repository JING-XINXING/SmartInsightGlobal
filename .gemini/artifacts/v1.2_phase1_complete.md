```bash

  -e POSTGRES_PASSWORD=test \
  -e POSTGRES_DB=test_smartinsight \

  postgres:15-alpine
```

## 📝 关键学习和最佳实践

### 1. 异步测试配置
```python
# 所有异步fixture必须使用 pytest_asyncio
@pytest_asyncio.fixture(scope="function")
async def db_session() -> AsyncGenerator[AsyncSession, Any]:
    ...

# pytest.ini 配置
[tool:pytest]
asyncio_mode = auto
markers =
    asyncio: 异步测试
```

### 2. 测试组织结构
```
tests/
├── test_api/      # API端点测试
├── test_core/     # 核心业务逻辑
├── test_models/   # 数据模型
└── test_utils/    # 工具函数
```

### 3. Mock策略
```python
# 使用 monkeypatch 进行依赖注入
@pytest.fixture
def mock_llm_client(self, monkeypatch):
    mock_client = Mock()
    mock_client.chat_completion = AsyncMock()
    monkeypatch.setattr("app.core.analyzer.llm_client", mock_client)
    return mock_client
```
