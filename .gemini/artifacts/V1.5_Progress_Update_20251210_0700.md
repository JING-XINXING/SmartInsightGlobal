// 使用 useTranslation hook
const { t } = useTranslation('auth')

// 表单验证
const loginSchema = z.object({

// UI 文本

### 导航栏 i18n 使用示例

// 导航菜单项
const mainNavItems = [
  { href: "/", label: t('common:goHome'), icon: TrendingUp },
  { href: "/dashboard", label: t('dashboard:title', { ns: 'dashboard' }), icon: TrendingUp },

  const roleMap = {

}

## 💡 经验总结

### 最佳实践
1. **命名空间分离**: 使用不同的命名空间 (common, auth, dashboard) 组织翻译
2. **类型安全**: TypeScript 确保翻译键的正确性
3. **渐进式迁移**: 逐页更新，每次更新后立即测试
4. **构建验证**: 每次更改后运行构建确保无错误

### 遇到的问题
1. **Zod 验证模式位置**: 需要将验证模式移到组件内部才能使用 `t()` 函数
   - 解决方案: 在组件内部定义 schema，使用 `useTranslation` hook

2. **命名空间语法**: 需要使用 `t('namespace:key')` 或 `t('key', { ns: 'namespace' })`
   - 解决方案: 统一使用 `t('namespace:key')` 语法更简洁
