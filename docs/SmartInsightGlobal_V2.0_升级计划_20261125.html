一、项目现状分析

1.1 项目概览

SmartInsight Global 是一个智能化的全球资讯采集与分析平台，当前版本 V1.5.0 已经建立了完善的后端架构，包括 17+ 国际主流媒体 RSS 新闻采集、6 大国产 LLM 智能分析引擎、JWT 认证 + RBAC 权限控制等核心功能。

2.2 后端架构优点

  • 模块化设计：API 路由按功能拆分，职责清晰
  • 异步架构：全链路异步 I/O（FastAPI + asyncpg + httpx）
  • 统一 LLM 接口：LLMClient 类设计优雅，支持多厂商切换和 Mock 回退
  • 高级 NLP 分析：AdvancedNLPAnalyzer 支持多模型融合分析
  • 完善的用户模型：角色、权限、会话、访问日志、审计日志
  • 数据库迁移：Alembic 管理，5 个迁移版本有序演进

2.3 后端架构不足

  • 数据库连接池：使用 NullPool（无池化），高并发下性能不佳
  • API 端点重复：存在 _simple 后缀的简化版与完整版并存，代码冗余
  • 测试文件混乱：根目录散落 test_*.py 文件
  • 缺少 API 速率限制：无请求频率控制
  • 依赖版本未锁定：requirements.txt 无版本号
  • 缺少全局异常处理：错误响应格式不统一

4.2 阶段规划

阶段一：基础修复与后端优化（V1.6）
  • 依赖版本锁定，创建 requirements-dev.txt 和 requirements-test.txt
  • 数据库连接池优化：NullPool → AsyncAdaptedQueuePool
  • 全局异常处理中间件，统一 API 错误响应格式
  • 合并重复 API 端点（_simple 版本 → 正式版本）
  • 测试文件整理（根目录 → tests/）
  • 编写后端 Dockerfile（多阶段构建）
  • 引入 slowapi 请求限流
阶段二：前端完整重建（V1.7）
  • 基于 Next.js 16 (App Router) + React 19 + TailwindCSS v4 重建
  • 13+ 页面：首页/登录/注册/新闻详情/地图/时间轴/搜索/仪表盘/分析/报告/资料/设置/历史
  • Shadcn/UI 组件库 + Zustand 状态管理
  • 全响应式设计（桌面 + 移动端）
  • 暗色/亮色主题、骨架屏、懒加载、SSR/SSG
阶段三：实时通信与高级功能（V1.8）
  • WebSocket 实时推送（新闻采集/分析完成通知）
  • LLM 智能路由策略（健康检查/负载均衡/熔断器）
  • 高级搜索和多维度组合筛选
  • 多格式数据导出（PDF/Excel/JSON/CSV）
阶段四：生产部署与质量保障（V1.9）
  • 后端测试覆盖率 ≥ 80%，前端 ≥ 70%
  • E2E 测试（Playwright）、性能测试（Locust）
  • Prometheus + Grafana 监控、结构化日志
  • 修复 GitHub Actions CI/CD
  • Nginx 反向代理配置（SSL/TLS + WebSocket）
阶段五：企业级功能（V2.0）
  • 多租户架构（数据隔离 + 租户管理 + 计费）
  • 订阅支付系统（免费/专业/企业）
  • 移动端升级（RN 新架构或 Expo）
  • 高可用部署（K8s + 数据库主从 + Redis Cluster + CDN）

五、技术架构改进

5.1 数据库连接池优化

当前: NullPool（无连接池） 改进: AsyncAdaptedQueuePool - pool_size: 10 - max_overflow: 20 - pool_timeout: 30 - pool_recycle: 3600

5.2 API 响应统一格式

{ "code": 200, "message": "success", "data": { ... }, "meta": { "page": 1, "page_size": 20, "total": 100 } }

5.3 LLM 智能路由架构

请求 → LLMRouter ├── 健康检查: 过滤不可用 provider ├── 负载均衡: 选择响应时间最短的 provider ├── 成本控制: 优先选择低成本模型 ├── 质量保障: 关键分析使用高质量模型 └── 熔断器: 连续失败自动切换

5.4 前端目录结构设计

app/ ├── (auth)/ # 认证页面 │ ├── login/ │ └── register/ ├── (main)/ # 功能页面 │ ├── page.tsx # 首页 │ ├── news/[id]/ # 新闻详情 │ ├── map/ # 全球热点地图 │ ├── events/ # 事件时间轴 │ ├── search/ # 搜索 │ ├── dashboard/ # 仪表盘 │ ├── analysis/ # 高级分析 │ ├── reports/ # 报告 │ ├── history/ # 分析历史 │ ├── profile/ # 个人资料 │ └── settings/ # 设置 ├── components/ # 共享组件 ├── hooks/ # 自定义 Hooks ├── lib/ # 工具函数 ├── stores/ # Zustand 状态管理 ├── types/ # TypeScript 类型 └── styles/ # 全局样式
