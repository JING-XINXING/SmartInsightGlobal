## 🚀 详细功能计划

### 1. 报告生成系统 (Frontend)
> 后端 `reports.py` 已就绪，需补全前端界面。

*   **报告中心页面** (`/reports`):
    *   报告列表（历史报告查看、下载）。
    *   新建报告向导（选择模板、时间范围、分析维度）。
*   **报告预览与导出**:
    *   支持 PDF/HTML 格式导出。
    *   集成图表（ECharts/Recharts）到静态报告中。

### 2. 国际化 (i18n) (Frontend)
> 后端 `i18n.py` 已就绪，需完成前端适配。

*   **架构**: 集成 `i18next` + `react-i18next`。
*   **翻译范围**: 导航栏、侧边栏、通用按钮、错误信息、图表图例。
*   **语言支持**: 简体中文 (zh-CN), 英文 (en-US)。
*   **动态切换**: 用户设置中增加语言偏好选项。

### 3. 移动端 App (Mobile)
> 当前处于基础框架阶段，需对接 V1.4 核心 API。

*   **认证对接**: 实现登录/注册页面，对接 JWT Auth 接口。
*   **新闻流**: 实现首页新闻列表下拉刷新、无限加载。
*   **地图集成**: 在移动端展示简版热点地图。

### 4. 测试与稳定性 (QA)
*   **后端修复**:
    *   解决 `test_get_events`, `test_get_map_clusters` 等失败用例。
    *   解决 `test_sentiment_analysis_neutral` 失败问题。
    *   Mock 数据库测试环境，解决 "PostgreSQL NOT running" 警告。
*   **前端测试**:
    *   补充 `analysis` 和 `auth` 模块的单元测试。
