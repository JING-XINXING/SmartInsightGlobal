## 📝 使用说明

### 启动后端服务
```bash
cd backend
uvicorn app.main:app --reload --port 8000
```

### 启动前端应用
```bash
cd frontend
npm run dev
```

### 手动触发数据采集
```bash
cd backend
python test_worker.py
```

### 启动 Celery Worker (定时任务)
```bash
cd backend
./start_worker.sh  # 启动 worker
./start_beat.sh    # 启动定时调度器
```
