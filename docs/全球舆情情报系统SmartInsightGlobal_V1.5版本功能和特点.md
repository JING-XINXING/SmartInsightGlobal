## 引言

在信息爆炸的时代，如何从海量的全球新闻资讯中快速获取有价值的情报洞察？**SmartInsight Global（智察全球）** 正是为解决这一痛点而生的开源项目。

## 一、项目定位

SmartInsight Global 是一个**智能化的全球资讯采集与分析平台**，通过整合多个国际主流媒体的 RSS 源，实时获取全球新闻动态，并集成国产大模型进行深度分析。

**适用场景**：
- 🏢 企业舆情监控与风险预警
- 📊 行业情报收集与竞争分析
- 🔬 学术研究与数据挖掘
- 📰 媒体从业者的内容聚合工具

## 二、V1.5 版本核心功能

### 2.1 🌍 全球情报采集引擎

聚合 **17+ 国际主流媒体**，覆盖全球主要新闻来源：

| 区域 | 媒体源 |
|------|--------|
| 欧美 | BBC、The Guardian、NYT、Washington Post、Reuters、AP News、CNN、CNBC |
| 中东 | Al Jazeera |
| 欧洲 | Deutsche Welle、France 24、The Economist |
| 亚太 | NHK World、South China Morning Post、Times of India |
| 科技 | TechCrunch |

- **异步并发采集**：高效处理大量RSS源
- **智能去重**：避免重复内容入库
- **定时更新**：Celery定时任务自动抓取

### 2.2 🤖 六大国产LLM智能分析

集成国内六大主流大语言模型，支持一键切换：

| 厂商 | 特点 |
|------|------|
| **DeepSeek** | 性价比之王，推理能力强 |
| **Qwen（通义千问）** | 阿里出品，多语言支持好 |
| **Moonshot（月之暗面）** | 长文本处理能力突出 |
| **智谱GLM** | 清华系，学术场景优化 |
| **百川** | 中文理解能力强 |
| **MiniMax** | 对话生成质量高 |

**AI分析能力**：
- 📈 **情感分析**：-100到100分值量化新闻情感倾向
- 🏷️ **关键词提取**：自动提取3-5个核心关键词
- 📑 **智能分类**：12个预定义类别自动归类
- 🧠 **实体识别(NER)**：提取人名、机构、地名
- 🔗 **关系抽取**：识别实体间的交互关系
- 📊 **趋势预测**：基于历史数据预测发展趋势

### 2.3 🗺️ 全球热点地图（V1.5增强）

**V1.5版本重点增强了地理位置功能**：

- **70+ 国家坐标映射库**：当LLM提取失败时智能回退
- **位置数据自动补充**：增强的backfill脚本支持批量处理
- **修复定位统计**：正确显示已定位新闻数量

**地图功能特性**：
- SVG世界地图可视化
- 新闻按地理位置聚合显示
- 情感指标颜色编码（正面/中性/负面）
- 热点地区排行榜
- 支持按分类筛选

**当前数据统计**：
- 📰 总新闻数：3180+
- 📍 已定位新闻：1353+ (42.5%)
- 🌍 覆盖国家/地区：131+

### 2.4 ⚙️ 用户偏好设置（V1.5新增）

全新的用户偏好设置API，支持个性化配置：

**通知设置**：
- 邮件通知开关
- 推送通知设置
- 通知频率配置（实时/每日/每周）
- 类型选择：新闻更新、报告就绪、系统告警

**用户偏好**：
- 语言设置（中文/英文）
- 时区设置
- 主题偏好（亮色/暗色）
- 每页显示数量
- 默认新闻分类

### 2.5 📜 分析历史记录（V1.5新增）

完整的分析历史管理功能：

| 功能 | 说明 |
|------|------|
| 历史管理 | 分页获取、筛选、搜索、删除、收藏 |
| 统计信息 | 总分析数、今日/本周/本月分析数、按类型统计 |

### 2.6 📅 事件时间轴

- 事件发展脉络展示

### 2.8 📊 数据可视化仪表盘

- 情感分布饼图

- 热门关键词词云

### 2.9 📄 智能报告生成

- 新闻深度分析报告

- 自定义报告模板

## 四、快速体验

### 环境要求

- Python 3.9+
- Node.js 18+
- PostgreSQL 15+
- Redis 7+

### 一键启动

```bash
# 克隆项目
git clone https://github.com/JING-XINXING/SmartInsightGlobal.git
cd SmartInsightGlobal

# 启动基础服务
docker-compose up -d

# 后端
cd backend
pip install -r requirements.txt
alembic upgrade head
uvicorn app.main:app --reload --port 8000

# 前端
cd frontend
npm install
npm run dev
```
