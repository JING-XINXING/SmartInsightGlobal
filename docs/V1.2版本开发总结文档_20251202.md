### 📋 V1.2版本技术栈

#### 后端技术栈
- **核心**: Python 3.10+ FastAPI + SQLAlchemy (Async)
- **缓存**: Redis (连接池管理)
- **数据库**: PostgreSQL 15 (索引优化)
- **任务队列**: Celery (Redis Broker)
- **测试**: pytest + pytest-asyncio + coverage
- **监控**: 自定义性能监控

#### 前端技术栈
- **框架**: Next.js 16 (App Router) + React 19
- **状态管理**: React Query + 自定义Hooks
- **样式**: TailwindCSS + 自定义组件
- **性能**: Web Vitals + 懒加载 + 代码分割
- **构建**: Webpack 5 + SWC
- **类型**: TypeScript 5.0 (严格模式)
- **测试**: Jest + Testing Library + React Testing
