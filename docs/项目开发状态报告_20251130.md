## 📊 项目概览

### 项目基本信息
- **项目名称**: SmartInsight Global (智察全球)
- **项目类型**: 智能全球情报分析系统
- **技术栈**: Python FastAPI + Next.js 16 + PostgreSQL + Redis + Celery
- **AI集成**: 6大国产大模型（DeepSeek、Qwen、Moonshot、智谱、百川、MiniMax）
- **当前版本**: V1.1 (已发布)

### 项目目标
1. **全球资讯采集**: 聚合17+国际主流媒体RSS源
2. **AI智能分析**: 情感分析、关键词提取、新闻分类、地理位置提取
3. **数据可视化**: 仪表盘、全球热点地图、事件时间轴
4. **全文搜索**: PostgreSQL全文检索支持
5. **数据安全**: 本地备份+云端同步双重保障

## ⚠️ 风险与问题识别

### 技术风险
1. **数据源稳定性**: RSS源可能变更或失效
2. **AI模型成本**: 多厂商API调用成本控制
3. **地理位置精度**: AI提取位置信息准确性
4. **事件聚类算法**: 简单相似度算法可能不够精确

### 运维风险
1. **单点故障**: 缺少高可用部署方案
2. **数据安全**: 需要加强访问控制
3. **性能瓶颈**: 大量数据时查询性能

### 业务风险
1. **版权合规**: 新闻转载需要遵循版权要求
2. **数据隐私**: 需要明确数据使用政策
