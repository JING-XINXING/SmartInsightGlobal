# SmartInsight Global - 快速使用指南

## 🚀 5分钟快速开始

### 步骤 1: 配置 API Key (必需)

编辑 `.env` 文件，添加您的 AI API Key：

```bash
# 选择其中一个即可
DEEPSEEK_API_KEY=sk-your-deepseek-api-key
# 或
QWEN_API_KEY=sk-your-qwen-api-key
# 或
OPENAI_API_KEY=sk-your-openai-api-key
```

**获取 API Key**:
- DeepSeek: https://platform.deepseek.com/
- Qwen: https://dashscope.aliyun.com/
- OpenAI: https://platform.openai.com/

---

### 步骤 2: 启动服务

打开 **3个终端窗口**：

#### 终端 1: 后端 API
```bash
cd backend
uvicorn app.main:app --reload --port 8000
```

#### 终端 2: Celery Worker
```bash
cd backend
celery -A app.worker.celery_app worker --loglevel=info
```

#### 终端 3: 前端
```bash
cd frontend
npm run dev
```

---

### 步骤 3: 访问应用

1. **打开浏览器**: http://localhost:3000
2. **查看新闻列表**: 已有 167+ 篇文章
3. **点击"数据分析"**: 查看可视化仪表盘

## 🔧 常见问题

### Q1: 为什么分析完成度是 0%？
**A**: 需要配置 API Key 并启动 Celery Worker。配置后等待 30 分钟，系统会自动分析。

### Q2: 如何立即看到分析结果？
**A**: 运行 `python test_analysis.py`，然后刷新仪表盘页面。

### Q3: Celery Worker 无法启动？
**A**: 确保 Redis 正在运行：
```bash
# macOS
brew services start redis

# 或使用 Docker
docker run -d -p 6379:6379 redis:7-alpine
```

### Q4: 前端无法连接后端？
**A**: 检查后端是否在 8000 端口运行：
```bash
curl http://localhost:8000/health
# 应返回: {"status":"ok"}
```

## 📝 自定义配置

### 修改采集频率
编辑 `backend/app/worker.py`:
```python
# 修改这一行，单位是秒
sender.add_periodic_task(3600.0, ...)  # 3600秒 = 1小时
```

### 添加新的新闻源
编辑 `backend/app/worker.py`:
```python
feeds = [
    "http://feeds.bbci.co.uk/news/world/rss.xml",
    "你的新RSS源URL",  # 添加这里
]
```

### 修改分析批次大小
编辑 `backend/app/worker.py`:
```python
# 修改这一行
select(News).where(News.sentiment_score == None).limit(10)  # 改为你想要的数量
```

## 🎓 高级用法

### 使用 Celery Beat 定时任务
```bash
cd backend
celery -A app.worker.celery_app beat --loglevel=info
```
这将启动定时调度器：
- 每小时自动采集新闻
- 每30分钟自动分析新闻

### 查看 Celery 任务状态
```bash
# 在 Python 中
from app.worker import fetch_news_task, analyze_news_task

# 手动触发任务
result = fetch_news_task.delay()
print(result.get())  # 等待结果
```

### 数据库查询
```bash
# 连接数据库
psql -h localhost -U xinxingjing -d smartinsight

# 查询统计
SELECT 
    category, 
    COUNT(*) as count,
    AVG(sentiment_score) as avg_sentiment
FROM news
WHERE category IS NOT NULL
GROUP BY category
ORDER BY count DESC;
```
