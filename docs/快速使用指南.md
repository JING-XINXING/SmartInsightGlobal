# SmartInsight Global - 快速使用指南

## 🚀 5分钟快速开始

### 步骤 1: 配置 API Key (必需)

编辑项目根目录的 `.env` 文件，添加您的 AI API Key（支持多个厂商，配置一个即可）：

```bash
# 选择其中一个或多个配置
DEEPSEEK_API_KEY=sk-your-deepseek-api-key
QWEN_API_KEY=sk-your-qwen-api-key
MOONSHOT_API_KEY=sk-your-moonshot-api-key
ZHIPU_API_KEY=your-zhipu-api-key
BAICHUAN_API_KEY=sk-your-baichuan-api-key
MINIMAX_API_KEY=your-minimax-api-key
```

**获取 API Key**:
| 厂商 | 申请地址 | 说明 |
|------|----------|------|
| DeepSeek | https://platform.deepseek.com/ | 推荐，性价比高 |
| 通义千问 | https://dashscope.aliyun.com/ | 阿里云，稳定 |
| Moonshot | https://platform.moonshot.cn/ | 月之暗面，长上下文 |
| 智谱 AI | https://open.bigmodel.cn/ | GLM 系列 |
| 百川智能 | https://platform.baichuan-ai.com/ | 国产大模型 |
| MiniMax | https://api.minimax.chat/ | ABAB 系列 |

---

### 步骤 2: 启动服务

打开 **3个终端窗口**：

#### 终端 1: 后端 API
```bash
cd backend
uvicorn app.main:app --reload --port 8000
```

#### 终端 2: Celery Worker
```bash
cd backend
celery -A app.worker.celery_app worker --loglevel=info
```

#### 终端 3: 前端
```bash
cd frontend
npm run dev
```

## 📊 仪表盘功能说明

访问 http://localhost:3000/dashboard 查看：

### 🤖 AI 模型选择

页面顶部提供两个下拉选择框，可以方便地切换 AI 分析模型：

1. **厂商选择**: DeepSeek、通义千问、Moonshot、智谱 AI、百川智能、MiniMax
2. **模型选择**: 根据选择的厂商显示可用模型列表

### ⏰ 定时任务设置

点击页面顶部的"定时任务"按钮，可以配置自动采集和分析的频率：

| 设置项 | 可选范围 | 说明 |
|--------|----------|------|
| 新闻采集频率 | 1-24 小时 | 每隔多少小时自动采集新闻 |
| 新闻分析频率 | 5-120 分钟 | 每隔多少分钟自动分析新闻 |
| 每次分析数量 | 10-100 篇 | 每次分析任务处理的新闻数量 |

### 核心指标卡片
- **总文章数**: 显示已采集的文章总数
- **平均情感**: 显示整体情感倾向 (-100 到 100)
- **风险指数**: 基于负面情感计算的风险值
- **已分析**: 显示 AI 分析完成的百分比

### 可视化图表
1. **情感分布饼图**: 正面/中性/负面文章比例
2. **新闻分类柱状图**: 各类别文章数量 Top 6
3. **来源分布图**: 各媒体来源的文章数量
4. **热门关键词**: 最常出现的 10 个关键词

## 🔧 常见问题

### Q1: 为什么分析完成度是 0%？
**A**: 需要配置 API Key 并启动 Celery Worker。配置后等待 30 分钟，系统会自动分析。

### Q2: 如何立即看到分析结果？
**A**: 运行 `python test_analysis.py`，然后刷新仪表盘页面。

### Q3: 厂商显示"未配置"怎么办？
**A**: 需要在 `.env` 文件中配置对应厂商的 API Key。配置后重启后端服务。

### Q4: 如何切换不同的 AI 模型？
**A**: 在仪表盘页面使用顶部的下拉选择框。

### Q5: 地图显示"暂无地理位置数据"？
**A**: 运行位置补充脚本:
```bash
cd backend
python backfill_locations.py --limit 200
```

### Q6: Celery Worker 无法启动？
**A**: 确保 Redis 正在运行：
```bash
# macOS
brew services start redis

# 或使用 Docker
docker run -d -p 6379:6379 redis:7-alpine
```

### Q7: 前端无法连接后端？
**A**: 检查后端是否在 8001 端口运行：
```bash
curl http://localhost:8001/health
# 应返回: {"status":"ok"}
```

## 📝 高级用法

### 使用 Celery Beat 定时任务
```bash
cd backend
celery -A app.worker.celery_app beat --loglevel=info
```

### API 接口调用

#### 新闻 API
```bash
# 分页获取新闻
curl "http://localhost:8000/api/v1/news/paginated?page=1&page_size=20"

# 搜索新闻
curl "http://localhost:8000/api/v1/news/search?q=关键词"

# 获取新闻详情
curl http://localhost:8000/api/v1/news/1
```

#### 地图 API (V1.1)
```bash
# 获取地图统计
curl http://localhost:8000/api/v1/map/stats

# 获取位置聚合
curl http://localhost:8000/api/v1/map/clusters
```

#### 事件 API (V1.1)
```bash
# 获取事件时间轴
curl "http://localhost:8000/api/v1/events/timeline?days=7"

# 获取热门话题
curl http://localhost:8000/api/v1/events/trending-topics
```

#### LLM 配置 API
```bash
# 查看当前配置
curl http://localhost:8000/api/v1/llm/current-config

# 获取厂商列表
curl http://localhost:8000/api/v1/llm/providers

# 更新配置
curl -X POST http://localhost:8000/api/v1/llm/update-config \
  -H "Content-Type: application/json" \
  -d '{"provider": "qwen", "model": "qwen-plus"}'
```
