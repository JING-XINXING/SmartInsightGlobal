# SmartInsight Global - 快速使用指南

## 🚀 5分钟快速开始

### 步骤 1: 配置 API Key (必需)

编辑 `backend/.env` 文件，添加您的 AI API Key（支持多个厂商，配置一个即可）：

```bash
# 选择其中一个或多个配置
DEEPSEEK_API_KEY=sk-your-deepseek-api-key
QWEN_API_KEY=sk-your-qwen-api-key
MOONSHOT_API_KEY=sk-your-moonshot-api-key
ZHIPU_API_KEY=your-zhipu-api-key
BAICHUAN_API_KEY=sk-your-baichuan-api-key
MINIMAX_API_KEY=your-minimax-api-key
```

**获取 API Key**:
| 厂商 | 申请地址 | 说明 |
|------|----------|------|
| DeepSeek | https://platform.deepseek.com/ | 推荐，性价比高 |
| 通义千问 | https://dashscope.aliyun.com/ | 阿里云，稳定 |
| Moonshot | https://platform.moonshot.cn/ | 月之暗面，长上下文 |
| 智谱 AI | https://open.bigmodel.cn/ | GLM 系列 |
| 百川智能 | https://platform.baichuan-ai.com/ | 国产大模型 |
| MiniMax | https://api.minimax.chat/ | ABAB 系列 |

---

### 步骤 2: 启动服务

打开 **3个终端窗口**：

#### 终端 1: 后端 API
```bash
cd backend
uvicorn app.main:app --reload --port 8000
```

#### 终端 2: Celery Worker
```bash
cd backend
celery -A app.worker.celery_app worker --loglevel=info
```

#### 终端 3: 前端
```bash
cd frontend
npm run dev
```

---

### 步骤 3: 访问应用

1. **打开浏览器**: http://localhost:3000
2. **查看新闻列表**: 全球主流媒体新闻（支持分页浏览）
3. **点击"数据分析"**: 查看可视化仪表盘
4. **选择 AI 模型**: 在仪表盘页面可切换不同厂商和模型
5. **配置定时任务**: 在仪表盘页面设置采集和分析频率

### ⏰ 定时任务设置 (新功能)

点击页面顶部的"定时任务"按钮，可以配置自动采集和分析的频率：

| 设置项 | 可选范围 | 说明 |
|--------|----------|------|
| 新闻采集频率 | 1-24 小时 | 每隔多少小时自动采集新闻 |
| 新闻分析频率 | 5-120 分钟 | 每隔多少分钟自动分析新闻 |
| 每次分析数量 | 10-100 篇 | 每次分析任务处理的新闻数量 |

> ⚠️ 配置修改后需要重启 Celery Beat 才能生效

### 核心指标卡片
- **总文章数**: 显示已采集的文章总数
- **平均情感**: 显示整体情感倾向 (-100 到 100)
- **风险指数**: 基于负面情感计算的风险值
- **已分析**: 显示 AI 分析完成的百分比

### 可视化图表
1. **情感分布饼图**: 正面/中性/负面文章比例
2. **新闻分类柱状图**: 各类别文章数量 Top 6
3. **来源分布图**: 各媒体来源的文章数量
4. **热门关键词**: 最常出现的 10 个关键词

## 🔧 常见问题

### Q1: 为什么分析完成度是 0%？
**A**: 需要配置 API Key 并启动 Celery Worker。配置后等待 30 分钟，系统会自动分析。

### Q2: 如何立即看到分析结果？
**A**: 运行 `python test_analysis.py`，然后刷新仪表盘页面。

### Q3: 厂商显示"未配置"怎么办？
**A**: 需要在 `backend/.env` 文件中配置对应厂商的 API Key。配置后重启后端服务。

### Q4: 如何切换不同的 AI 模型？
**A**: 在仪表盘页面 (http://localhost:3000/dashboard) 使用顶部的下拉选择框：
1. 先选择厂商（如：DeepSeek）
2. 再选择模型（如：deepseek-chat）
3. 选择后自动保存，新的分析任务将使用该模型

### Q5: 如何修改定时任务频率？
**A**: 在仪表盘页面点击"定时任务"按钮：
1. 设置新闻采集频率（1-24小时）
2. 设置新闻分析频率（5-120分钟）
3. 设置每次分析数量（10-100篇）
4. 点击"保存"后重启 Celery Beat

### Q6: Celery Worker 无法启动？
**A**: 确保 Redis 正在运行：
```bash
# macOS
brew services start redis

# 或使用 Docker
docker run -d -p 6379:6379 redis:7-alpine
```

### Q7: 前端无法连接后端？
**A**: 检查后端是否在 8000 端口运行：
```bash
curl http://localhost:8000/health
# 应返回: {"status":"ok"}
```

## 📝 自定义配置

### 修改采集频率
编辑 `backend/app/worker.py`:
```python
# 修改这一行，单位是秒
sender.add_periodic_task(3600.0, ...)  # 3600秒 = 1小时
```

### 添加新的新闻源
编辑 `backend/app/worker.py`:
```python
feeds = [
    "http://feeds.bbci.co.uk/news/world/rss.xml",
    "你的新RSS源URL",  # 添加这里
]
```

### 修改分析批次大小
现在可以在 Web 页面的"定时任务"设置中直接修改，无需编辑代码。

## 🎓 高级用法

### 使用 Celery Beat 定时任务
```bash
cd backend
celery -A app.worker.celery_app beat --loglevel=info
```
定时调度器会根据 Web 页面中的配置执行：
- 默认每 1 小时自动采集新闻（可配置 1-24 小时）
- 默认每 30 分钟自动分析新闻（可配置 5-120 分钟）

### 调度器 API 接口

查看当前调度器配置：
```bash
curl http://localhost:8000/api/v1/scheduler/config
```

更新调度器配置：
```bash
curl -X POST http://localhost:8000/api/v1/scheduler/config \
  -H "Content-Type: application/json" \
  -d '{"fetch_interval_hours": 2, "analyze_interval_minutes": 15}'
```

查看调度器状态：
```bash
curl http://localhost:8000/api/v1/scheduler/status
```

### 查看 Celery 任务状态
```bash
# 在 Python 中
from app.worker import fetch_news_task, analyze_news_task

# 手动触发任务
result = fetch_news_task.delay()
print(result.get())  # 等待结果
```

### 新闻 API 接口

分页获取新闻列表：
```bash
# 获取第1页，每页20条
curl "http://localhost:8000/api/v1/news/paginated?page=1&page_size=20"

# 获取新闻详情
curl http://localhost:8000/api/v1/news/1

# 获取新闻总数
curl http://localhost:8000/api/v1/news/count
```

### LLM API 接口

查看当前 LLM 配置：
```bash
curl http://localhost:8000/api/v1/llm/current-config
```

获取所有厂商列表：
```bash
curl http://localhost:8000/api/v1/llm/providers
```

获取指定厂商的模型列表：
```bash
curl http://localhost:8000/api/v1/llm/models/deepseek
```

更新 LLM 配置：
```bash
curl -X POST http://localhost:8000/api/v1/llm/update-config \
  -H "Content-Type: application/json" \
  -d '{"provider": "qwen", "model": "qwen-plus"}'
```

### 数据库查询
```bash
# 连接数据库
psql -h localhost -U xinxingjing -d smartinsight

# 查询统计
SELECT 
    category, 
    COUNT(*) as count,
    AVG(sentiment_score) as avg_sentiment
FROM news
WHERE category IS NOT NULL
GROUP BY category
ORDER BY count DESC;
```
