## ⚠️ 存在的问题与不足

### 1. 功能层面

| 问题 | 严重程度 | 说明 |
|------|----------|------|
| 地图简化 | 低 | 使用 SVG 简化大陆轮廓，非精确地图 |
| 历史位置数据缺失 | 中 | 已分析的新闻需运行补充脚本 |
| 事件聚类简单 | 低 | 基于 Jaccard 相似度，可能不够精确 |
| 无用户认证 | 中 | 所有数据公开，无权限控制 |

### 2. 技术层面

| 问题 | 严重程度 | 说明 |
|------|----------|------|
| 缺少单元测试 | 高 | 后端缺少 pytest 测试用例 |
| 缺少前端测试 | 高 | 前端缺少 Jest/Vitest 测试 |
| 无 CI/CD | 中 | 缺少自动化部署流程 |
| 无 Docker 生产配置 | 中 | 只有开发环境 docker-compose |
| API 无速率限制 | 低 | 可能被滥用 |

### 3. 用户体验

| 问题 | 严重程度 | 说明 |
|------|----------|------|
| 无移动端适配 | 中 | 部分页面在移动端显示不佳 |
| 无深色模式切换 | 低 | 依赖系统主题 |
| 无加载骨架屏 | 低 | 数据加载时体验一般 |
| 无错误边界 | 低 | 组件错误可能导致白屏 |
