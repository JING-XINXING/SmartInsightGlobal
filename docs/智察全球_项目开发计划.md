# 智察全球（SmartInsight Global）项目开发计划

## 总体路线图
本计划基于《智察全球项目开发文档 v1.0》制定，旨在分阶段有序推进项目开发，确保从基础架构到核心功能的稳步落地。

---

## 第一阶段：MVP 基础架构与数据采集 (预计周期：2-3周)
**目标**：跑通“数据采集 -> 存储 -> 基础展示”的全流程，搭建稳固的系统地基。

### 1. 基础设施搭建 (Infrastructure)
- [x] **项目初始化**：建立 Monorepo 结构 (Backend/Frontend/Scripts)。
- [x] **Docker环境**：编写 `docker-compose.yml`，编排 PostgreSQL, Redis, MinIO (可选，本地对象存储模拟) 服务。
- [ ] **数据库设计**：
    - [x] 设计 `News` 表 (标题, 内容, 来源, 发布时间, 原始链接)。
    - [x] 设计 `Source` 表 (RSS源, API配置, 采集频率)。
    - [x] 初始化 Alembic (Python) 或 Prisma (Node) 迁移脚本。

### 2. 后端开发 (Backend - Python/FastAPI)
- [x] **框架搭建**：配置 FastAPI, Pydantic, SQLAlchemy/Tortoise-ORM。
- [x] **测试环境**：配置 Pytest 及数据库测试 Fixture。
- [ ] **采集引擎 (Crawler Core)**：
    - [x] 实现通用 RSS 解析器 (使用 `feedparser`)。
    - [x] 实现基础 HTTP 请求封装 (处理 User-Agent, Retry, Proxy)。
    - [x] 接入 5-10 个主流国际新闻源 RSS。
- [ ] **任务调度**：
    - [x] 配置 Celery + Redis，实现定时采集任务。

### 3. 前端开发 (Frontend - Next.js)
- [x] **框架搭建**：初始化 Next.js (App Router), 配置 TailwindCSS。
- [x] **UI 组件库**：安装并配置 Shadcn/UI (Lucide React, CLSX, Tailwind Merge)。
- [ ] **基础页面**：
    - [x] **信息流页面**：展示采集到的原始新闻列表 (按时间排序)。
    - [ ] **详情页**：展示新闻详情 (目前仅展示原始内容)。

---

## 第二阶段：V1.0 智能分析与核心功能 (预计周期：3-4周) ✅ 已完成
**目标**：接入国产大模型，实现数据的“智能增值”，完成仪表盘与备份系统。

### 1. AI 智能分析引擎 (AI Engine)
- [x] **模型接入**：
    - [x] 封装统一 LLM Client (兼容 OpenAI 格式，指向 DeepSeek/Qwen API)。
    - [x] 配置 API Key 管理与轮询机制。
- [x] **Prompt 工程**：
    - [x] 开发“新闻摘要”提示词模板。
    - [x] 开发“情感分析”与“关键词提取”提示词。
- [x] **分析流水线**：
    - [x] 在 Celery 中增加 `analyze_task`，采集后自动触发 AI 分析。
    - [x] 将 AI 分析结果 (摘要, 情感, 标签) 存入数据库。

### 2. 数据可视化与仪表盘 (Dashboard)
- [x] **全球热点地图**：集成 ECharts/Leaflet，在地图上标记新闻发生地及热度。
- [x] **风险指数看板**：根据 AI 分析的情感负面值，计算并展示“全球/地区风险指数”。
- [x] **事件时间轴**：开发 Timeline 组件，串联相关事件的发展脉络。

### 3. 数据安全与备份 (Security & Backup)
- [ ] **本地备份**：编写 Shell 脚本，每日定时 `pg_dump` 导出数据库并压缩至本地指定硬盘目录。
- [ ] **云端同步**：集成 `rclone` 或编写 Python 脚本，将备份文件同步至对象存储 (OSS/S3)。
- [ ] **自动恢复测试**：编写文档说明如何从备份文件恢复数据库。

## 第三阶段：V1.1 体验优化与移动端适配 (预计周期：2周)
**目标**：打磨产品体验，使其达到“商业级”的视觉与交互标准。

### 1. 移动端适配 (Mobile First)
- [ ] 优化 Next.js 响应式布局，确保在手机浏览器上有原生 App 般的体验。
- [ ] 增加 PWA 支持 (Manifest, Service Worker)，支持添加到手机桌面。

### 2. 搜索与筛选
- [ ] 实现全文检索 (基于 PostgreSQL Full Text Search 或 MeiliSearch)。
- [ ] 增加按国家、话题、时间范围的高级筛选功能。

### 3. 报告生成
- [ ] 开发“日报/周报”生成器，汇总一段时间的高频词与重大事件，由 AI 撰写综述。
- [ ] 支持导出为 Markdown 或 PDF。
