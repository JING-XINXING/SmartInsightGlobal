## 🎯 详细功能规格

### 1. 通知设置

#### 功能描述
用户可以自定义接收哪些类型的通知，以及通过什么渠道接收。

#### 技术实现
- 前端: React Hook Form + Zod 验证
- 后端: 用户偏好设置 API
- 存储: PostgreSQL users.notification_settings

#### 界面设计
```
通知设置
├── 邮件通知
│   ├── 新闻更新通知 [开关]
│   ├── 分析完成通知 [开关]
│   └── 系统公告 [开关]
├── 推送通知
│   ├── 浏览器推送 [开关]
│   └── 移动端推送 [开关]
└── 通知频率
    ├── 实时
    ├── 每小时汇总
    └── 每日摘要
```

---

### 2. 主题切换

#### 功能描述
支持亮色/暗色主题切换，以及自定义主题色。

#### 技术实现
- 前端: TailwindCSS dark mode
- 存储: LocalStorage + 用户偏好
- 动态切换: CSS 变量

#### 主题选项
- 亮色主题 (默认)
- 暗色主题
- 自动 (跟随系统)
- 主题色: 蓝色/绿色/紫色/橙色

---

### 3. 分析历史记录

#### 功能描述
保存用户的所有分析记录，支持查看、搜索、导出。

#### 数据模型
```sql
CREATE TABLE analysis_history (
    id SERIAL PRIMARY KEY,
    user_id INTEGER REFERENCES users(id),
    news_id INTEGER REFERENCES news(id),
    analysis_type VARCHAR(50),
    results JSONB,
    created_at TIMESTAMP WITH TIME ZONE
);
```

#### API 端点
- `GET /api/v1/analysis/history` - 获取历史记录
- `GET /api/v1/analysis/history/{id}` - 获取单条记录
- `DELETE /api/v1/analysis/history/{id}` - 删除记录
- `POST /api/v1/analysis/history/export` - 导出记录
