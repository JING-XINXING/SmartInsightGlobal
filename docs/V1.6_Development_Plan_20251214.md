## 📊 功能详细规格

### 1. 设置页面功能

#### 1.1 通知设置

```typescript
interface NotificationSettings {
  email_enabled: boolean;      // 邮件通知
  push_enabled: boolean;       // 推送通知
  frequency: 'realtime' | 'daily' | 'weekly';
  news_updates: boolean;       // 新闻更新通知
  report_ready: boolean;       // 报告就绪通知
  system_alerts: boolean;      // 系统告警
}
```

#### 1.2 外观设置

```typescript
interface AppearanceSettings {
  theme: 'light' | 'dark' | 'system';
  accent_color: string;        // 主题色
  font_size: 'small' | 'medium' | 'large';
}
```

### 2. 分析历史前端

#### 2.1 历史列表组件

```tsx
<AnalysisHistoryList
  filters={{
    type: 'sentiment' | 'entity' | 'all',
    dateRange: [startDate, endDate],
    isFavorite: boolean
  }}
  onExport={(format) => void}
  onDelete={(id) => void}
/>
```

#### 2.2 统计卡片组件

```tsx
<AnalysisStatistics
  stats={{
    total: number,
    today: number,
    thisWeek: number,
    byType: Record<string, number>
  }}
/>
```
