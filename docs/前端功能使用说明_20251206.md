## 🚀 快速开始

### 1. 启动服务

#### 前端服务
```bash
cd frontend
npm run dev
```
访问地址: http://localhost:3001

#### 后端服务
```bash
cd backend
uvicorn app.main:app --reload
```
API文档: http://localhost:8000/docs

### 2. 核心功能

#### ✅ JWT认证系统 (已完成)
- **用户注册**: 访问 `/register`

## 📱 使用指南

### 认证流程

#### 1. 新用户注册
1. 访问 http://localhost:3001/register
2. 填写用户名、邮箱、密码等信息
3. 系统自动登录并跳转到首页

#### 2. 用户登录
1. 访问 http://localhost:3001/login
2. 输入用户名和密码
3. 登录成功后自动跳转

#### 3. 权限说明
- **Admin**: 系统管理员，拥有所有权限
- **Analyst**: 数据分析师，可进行分析操作
- **Viewer**: 只读用户，可查看分析结果
- **Guest**: 访客用户，有限的查看权限

### 高级分析使用

#### 1. 综合分析
1. 确保已登录并有分析师权限
2. 访问 http://localhost:3001/analysis
3. 选择"综合分析"标签页
4. 输入新闻标题和内容
5. 点击"开始分析"
6. 查看分析结果：
   - 情感分数和置信度
   - 识别出的实体和类型
   - 实体间关系
   - 趋势预测结果

#### 2. 情感分析
1. 在分析页面选择"情感分析"标签页
2. 选择分析模式（单模型/多模型）
3. 输入标题和内容
4. 查看详细的情感分析结果和模型对比

#### 3. 实体识别
1. 在分析页面选择"实体识别"标签页
2. 是否启用关系分析
3. 输入标题和内容
4. 查看识别出的实体和关系网络

## 🔧 技术特性

### 前端技术栈
- **框架**: Next.js 16 + React 19
- **语言**: TypeScript (100%覆盖)
- **UI库**: Radix UI + TailwindCSS
- **状态管理**: Zustand + Persist中间件
- **表单处理**: React Hook Form + Zod验证
- **HTTP客户端**: Axios + 拦截器

### 安全特性
- **JWT认证**: 访问令牌 + 刷新令牌
- **自动刷新**: 令牌过期前自动续期
- **CSRF防护**: SameSite Cookie策略
- **权限控制**: 基于角色的访问控制
- **XSS防护**: 输入验证和输出转义

### 用户体验
- **响应式设计**: 完美适配桌面端和移动端
- **加载状态**: 优雅的加载指示器
- **错误处理**: 用户友好的错误提示
- **离线支持**: 本地状态缓存

## 🐛 常见问题

### Q: 前端启动失败，提示端口占用
**A**:
1. 查找占用进程: `lsof -ti:3000 | xargs kill`
2. 或者使用其他端口启动: `npm run dev -- -p 3002`

### Q: 登录后显示"无权限访问"
**A**:
1. 确认用户角色具有相应权限
2. 联系管理员分配正确权限
3. 或者使用admin账户测试

### Q: 高级分析功能无法使用
**A**:
1. 确认后端服务正常运行 (http://localhost:8000)
2. 确认用户具有analyst或admin权限
3. 检查网络连接和API响应

### Q: 页面刷新后登录状态丢失
**A**:
1. 清除浏览器缓存
2. 检查Cookie设置
3. 重新登录
